# 冠军答辩手册

## 90 秒主叙事

我们做的不是“让模型直接生成一条视频”，而是一个可解释、可调整、可验证的 AI 视频创作平台。系统先理解优质样例，把 Hook、镜头节奏、字幕密度、包装标签、卖点推进和 CTA 抽成结构；再把这些结构迁移到新商品和真实素材上；素材不够时，系统会明确指出缺口，并用结构重排、字幕补全、包装补全、AIGC 占位和素材复用完成创作闭环。最后 Remotion 按同一份 `RenderTimeline` 输出有声竖屏视频，质量门禁验证分辨率、帧率、音频和码率。

一句话：我们迁移的是爆款方法，不是复刻爆款内容。

## 最强演示路径

1. 打开首页，选择“咖啡新品”预设。
2. 点击“拆解成结构卡片”，先看结构指纹。
3. 点击“生成迁移方案”，先停在“冠军验收台”：这里按官方评分表展示基础分、加分项和证据位置。
4. 展示“手法迁移配方”：逐行解释源样例时间段如何映射到新片段。
5. 展示“真实素材资产”：说明产品图、微距、工位、收尾图分别支撑哪些结构槽位。
6. 播放 `submissions/final-coconut-latte/final-video.mp4`，指出画面上直接标注了“源 0-2s / 源 5-8s / 源 12-15s”。
7. 打开 `submissions/final-coconut-latte/quality-report.json`，展示最终视频质量 `100/100` 且有音频。
8. 展示 Markdown 导出稿中的“官方评分表拆解”和“样例-结果手法对比”。

## 评委追问回答

### 这是不是只套模板？

不是。模板只是渲染层，真正驱动结果的是 `TechniqueTransferRecipe`。它保存源样例时间段、源手法目的、可迁移规则、新片段、字幕密度、转场倾向、素材状态和补全计划。页面和视频都会把这条链路显示出来。

### 为什么不用视频模型直接生成？

直接生成一条片子很难解释结构迁移，也不容易控制素材缺口。本项目把视频模型放在素材补全位置，最终结构、时间线、字幕、包装和音频由项目协议控制，更符合题目要求。

### 素材不足怎么办？

系统把结构拆成开头吸引、主体特写、使用过程、对比结果、背书证据、结尾 CTA 六类槽位。每个槽位会展示匹配素材、缺口影响和补全策略。缺素材时不硬编，而是用包装、字幕、结构重排或 AIGC 占位补足表达。

### 怎么证明能上交？

运行：

```bash
npm run verify
npm run award:check
npm run champion:check
npm run demo:final -- --out-dir submissions/final-coconut-latte --quality high
npm run submission:pack -- --include-final-demo-dir submissions/final-coconut-latte
```

这些命令分别覆盖工程质量、离线案例、官方评分表、最终有声视频和提交压缩包。

## 风险边界

- 不提交 `.env`、API Key、上传素材、本地数据库和渲染产物。
- 不复制样例的具体人物、台词、品牌和镜头，只迁移创作结构。
- 背书、评价、参数和数据必须可追溯。
- AIGC 视觉只补素材槽位，不替代结构迁移逻辑。
